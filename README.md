# Numerical Analysis for Energy Resources Engineering

This repository provides Python code and Jupyter Notebook examples for the course **Numerical Analysis for Energy Resources Engineering**, offered by the **Department of Energy Resources Engineering, Inha University**, in the **Fall Semester of 2026**.

## Course Information

* **Course:** Numerical Analysis for Energy Resources Engineering
* **Department:** Department of Energy Resources Engineering
* **University:** Inha University
* **Semester:** Fall 2026
* **Author:** Sukjun Pyun
* **Created:** August 24, 2026
* **Programming Language:** Python
* **Primary Environment:** Jupyter Notebook

## About This Repository

The purpose of this repository is to provide computational examples that support the numerical methods and engineering concepts covered in the course.

The materials are primarily provided as **Jupyter Notebooks (`.ipynb`)** and are intended to help students:

* understand fundamental numerical methods through computational examples,
* implement numerical algorithms using Python,
* visualize numerical results,
* examine the accuracy, convergence, and limitations of numerical methods, and
* apply numerical techniques to problems relevant to energy resources engineering.

## Contents

The repository contains Python examples and exercises related to topics covered throughout the course. Depending on the course schedule, these may include:

* Fundamentals of numerical computation
* Errors and numerical accuracy
* Root finding
* Systems of linear equations
* Interpolation and curve fitting
* Numerical differentiation
* Numerical integration
* Ordinary differential equations
* Optimization
* Applications to energy resources engineering

The contents may be updated or reorganized during the semester according to the progress of the course.

## Requirements

The notebooks are primarily written in Python and may use commonly available scientific computing libraries, including:

* NumPy
* SciPy
* Matplotlib
* SymPy
* Pandas

Additional packages may be required for individual notebooks.

## Usage

Students may clone this repository or download individual notebooks and run them in a local Jupyter environment.

```bash
git clone <repository-url>
```

The notebooks can also be opened using environments such as Jupyter Notebook, JupyterLab, or compatible Python IDEs.

## Notes for Students

The code provided in this repository is intended to supplement lectures and help students understand the numerical methods discussed in class.

Students are encouraged to modify the examples, change parameters, test different numerical conditions, and examine how these changes affect the results.

The materials in this repository do not necessarily replace lecture notes, textbooks, assignments, or other course materials.
